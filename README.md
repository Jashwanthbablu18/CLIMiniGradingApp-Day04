# 🎓 Day 4 - Mini Grading App

Hey there! 👋  
Welcome to **Day 4** of my **#30DaysOfPythonChallenge**. Today’s project is a simple yet powerful grading app that puts Python's core operators to the test!

---

## 📌 What’s This About?
Today’s focus: **Python Operators** — the building blocks for logic and computation in any Python program. This project is a fun way to see them all in action.

---

## 💭 Why This Project?
Whether you're doing math, comparing values, or making decisions in your code, **operators** are everywhere. This grading app is a practical way to apply:
- Arithmetic
- Assignment
- Comparison
- Logical
- Identity Operators

---

## ✨ Features

Here’s what the app can do:
- 🔢 Accept a score from 0 to 100
- ✅ Validate the input range
- 🎁 Add bonus points if the score is low
- 🏆 Determine and display the grade
- 🔍 Make decisions using logical and comparison operators

---

## 🛠️ Tech Stuff

Built with:
- 🐍 **Python 3**
- 📥 User input handling
- 🔀 Type casting with `int()`
- ⚙️ All major types of Python operators

---

## 🧠 Operators in Action

Used in this project:
- ➕ ➖ ✖️ ➗ `+`, `-`, `*`, `/` — *Arithmetic*
- 🟰 `=`, `+=` — *Assignment*
- 🔁 `==`, `!=`, `>=`, `<=` — *Comparison*
- 🔗 `and`, `or`, `not` — *Logical*
- 🪞 `is`, `is not` — *Identity (optional showcase)*
